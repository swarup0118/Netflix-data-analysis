# Netflix Data Analysis (2008–2021)

## Project Overview
This project analyzes the Netflix dataset from 2008 to 2021 to explore content distribution and trends across Movies and TV Shows. Using Exploratory Data Analysis (EDA), the project investigates genres, ratings, release patterns, and country contributions to understand Netflix's content library.

## Objectives
- Analyze the distribution of Movies and TV Shows.
- Identify popular genres and content categories.
- Explore content ratings and audience classifications.
- Examine country-wise contributions to Netflix content.
- Identify trends and patterns through data visualization.
- Provide data-driven insights and recommendations for content acquisition and global audience engagement.

## Tools and Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Project Workflow
1. Load the Netflix dataset.
2. Inspect the dataset structure and data types.
3. Clean the data and handle missing values.
4. Perform Exploratory Data Analysis (EDA).
5. Analyze content types, genres, ratings, and countries.
6. Create visualizations to communicate key patterns.
7. Summarize insights and recommendations.

## Key Areas of Analysis
- Movies vs. TV Shows distribution
- Genre and category analysis
- Content rating analysis
- Country-wise content distribution
- Content trends over time

## Business Insights
The analysis aims to help understand Netflix's content mix, genre diversity, geographic representation, and content trends. These insights can support informed decisions about content acquisition and audience engagement.
